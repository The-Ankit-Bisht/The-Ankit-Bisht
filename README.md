## 🚀 Featured Projects

### 📦 SupplyPrescript — Supply Chain Risk Intelligence

**Machine Learning · Predictive Analytics · Full-Stack Development**

An end-to-end application for predicting shipment disruptions and estimating delivery lead times.

- 📊 Analyzed **5,000 shipment records** across 14 original attributes.
- 🤖 Developed machine learning models for disruption classification and lead-time prediction.
- 🎯 Achieved **72.6% classification accuracy**.
- 📉 Achieved approximately **0.98 days MAE** for lead-time prediction.
- 🌐 Built an interactive React dashboard backed by FastAPI and PostgreSQL/Supabase.
- 💡 Provides shipment risk predictions, transport comparisons, and actionable recommendations.

**Tech Stack:** Python · Pandas · Scikit-learn · FastAPI · React · PostgreSQL · Supabase

🔗 [Explore my GitHub repositories](https://github.com/The-Ankit-Bisht?tab=repositories)
